既存アプリ `khaki1981/AIPruningAssistant` の**コードは一切変更していません**。本フォルダは参照用のデザイン提案です。実装は `../../` にある既存プロジェクトを別途参照してください。

## 参照した既存画面・情報
- `docs/concept.md`（プロダクトコンセプト）
- `src/App.tsx`（現行の単一画面フォーム：写真アップロード＋入力＋Gemini診断表示）
- `src/styles.css`（現行の色・トーン）
- 上記をもとに作成済みの **AI Pruning Assistant デザインシステム**（トークン＋コンポーネント）を最優先で使用。

現行は「1画面フォーム」に機能が集約されているため、**役割ごとに画面を分割し、導線を明確化**しました。

## 作成した画面（1つのHTMLで切り替え可能）
`index.html` 内でスマホ実機のように画面遷移します。ヘッダー右上の田の字アイコン＝**画面マップ**、下部中央の緑ボタン＝**AI診断**。

1. 画面マップ／ユーザー導線（全画面へジャンプ可能）
2. ホーム（2つの入口を最優先で提示）
3. 植物検索（検索＋カテゴリー＋植物カード）
4. 植物詳細（タブ：概要／剪定／肥料・水／コツ）
5. 写真アップロード（撮影のコツ＋樹木名入力）
6. 剪定条件の選択（強さ3択＋目的の複数選択）
7. AI分析中（進行状況＋安心メッセージ）
8. AI分析結果（要約→切る/残す枝→確信度→専門家相談）
9. 剪定手順（ステップ＋完了チェック＋進捗バー）
10. 履歴（剪定前後の写真比較・メモ）
- 付随：ボトムナビ／空・ローディング表現／確認モーダル／トースト通知

## ユーザー導線
ホーム → ①写真でAI診断：アップロード → 条件選択 → 分析中 → 結果 → 手順 → 履歴に記録
　　　　→ ②植物名で調べる：検索 → 詳細 →（そのままAI診断へ）

## デザイン上の改善点
- **入口を2つに集約**（写真AI診断／名前で検索）。迷わない。
- 情報過多の詳細画面を**タブで整理**、専門用語に平易な補足。
- 剪定の強さ・目的を**カード型選択**に（ラジオより押しやすく分かりやすい）。
- AI結果は**重要順（要約→枝→注意）**。断定を避け「推定」「確信度」「参考情報」を明示。
- **専門家相談の注意**を結果・分析中に常設（高所/太枝/電線）。
- 状態は**色＋アイコン＋文字**で表現（色覚差・屋外対応）。

## 採用したナビゲーション
ボトムナビ5枠：ホーム／植物／**AI診断（中央・浮き出し強調）**／履歴／設定。診断を最重要操作として中央に配置。

## デザインシステムから使用した要素
- **色**：主役=緑 `--color-primary #2E7D4F` ／ 補助=茶 `--color-secondary` ／ 差し色=水色 `--color-accent`・黄 `--color-season`。背景はアイボリー `--color-bg #F6F4EC`、面は白。
- **文字**：見出し=明朝 Shippori Mincho ／ 本文・UI=ゴシック Noto Sans JP。本文15px以上・行間ゆったり。
- **余白・角丸・影**：`--space-*`（16/24/48）、カード14px・ボタン10px、緑みの柔らかい影。タップ領域44px以上、主ボタン52〜58px。
- **コンポーネント**：PageTitle / SearchBar / Tag / PlantCard / Input / UploadArea / Button / IconButton / Radio(カード) / SeasonBadge / StatusBadge / AnalysisResultCard / StepCard / AlertBox / Modal / Toast / Icon(Lucide)。

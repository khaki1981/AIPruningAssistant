# AI Pruning Assistant（剪定AIアシスタント）

植物名から庭木を選び、登録済みの植物データを使って剪定情報を確認するWebアプリです。

現バージョンは、植物データから現在時期の剪定案内を表示する機能と、Supabase Authによるメール・パスワード認証の基盤を実装しています。写真から植物の候補を調べる機能は準備中です。

## 技術構成

- React
- TypeScript
- Vite
- CSS
- Supabase Auth

## ローカルでの起動

Node.jsをインストールした環境で、次のコマンドを実行します。

```bash
npm install
npm run dev
```

ターミナルに表示されるURL（通常は `http://localhost:5173`）をブラウザで開いてください。

本番用のビルド確認は次のコマンドで行えます。

```bash
npm run build
```

Supabase認証をローカルで利用する場合は、[Supabase認証セットアップ](docs/supabase-auth-setup.md)も参照してください。

## 植物データの表示範囲

ローカル開発とNetlify Deploy Previewでは全植物を表示し、本番とbranch deployでは`reviewStatus`が`verified`の植物だけを表示します。`VITE_PLANT_DATA_VISIBILITY`は表示範囲を切り替える公開設定であり、秘密情報ではありません。表示確認のために植物JSONの`reviewStatus`を変更しないでください。

## 現在の機能

- 植物名検索、植物詳細、植物の確定
- 植物JSONに基づく現在時期の剪定案内
- メールアドレスとパスワードによる登録・ログイン・ログアウト
- スマートフォンに対応したレスポンシブ表示

## 将来追加したい機能

- 写真から植物名の候補を提示する機能
- 剪定後のイメージ画像生成
- 作業履歴の保存
- 剪定前・剪定後の写真比較
- 樹木ごとの管理
- 季節ごとの剪定アドバイス
- 元写真に赤線・番号をつけて、切る候補を示す機能

## 注意事項

剪定案内は参考情報として扱い、木の状態、樹種、地域、季節を確認したうえで作業してください。高所、太い枝、電線付近など危険を伴う作業は専門家へ依頼してください。

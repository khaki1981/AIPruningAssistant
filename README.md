# AI Pruning Assistant（剪定AIアシスタント）

木の写真と樹木名、希望する剪定の強さ、気になる点を入力し、剪定方針を整理する個人用Webアプリです。

現バージョンは、植物データから現在時期の剪定案内を表示する機能、写真を使ったAI診断、Supabase Authによるメール・パスワード認証の基盤を実装しています。

## 技術構成

- React
- TypeScript
- Vite
- CSS
- Supabase Auth

## ローカルでの起動

Node.jsをインストールした環境で、次のコマンドを実行します。

```bash
npm install
npm run dev
```

ターミナルに表示されるURL（通常は `http://localhost:5173`）をブラウザで開いてください。

本番用のビルド確認は次のコマンドで行えます。

```bash
npm run build
```

Supabase認証をローカルで利用する場合は、[Supabase認証セットアップ](docs/supabase-auth-setup.md)も参照してください。

## 現在の機能

- 木の写真を複数選択してプレビュー表示
- 選択した写真の個別削除
- 樹木名の入力
- 剪定の強さの選択
- 気になる点の入力
- 植物名検索、植物詳細、植物の確定
- 植物JSONに基づく現在時期の剪定案内
- Gemini APIを利用したAI診断
- メールアドレスとパスワードによる登録・ログイン・ログアウト
- スマートフォンに対応したレスポンシブ表示

## 将来追加したい機能

- ChatGPT API または Gemini API による画像診断
- 剪定後のイメージ画像生成
- 作業履歴の保存
- 剪定前・剪定後の写真比較
- 樹木ごとの管理
- 季節ごとの剪定アドバイス
- 元写真に赤線・番号をつけて、切る候補を示す機能

## 注意事項

AIによる診断は参考情報として扱い、木の状態、樹種、地域、季節を確認したうえで作業してください。高所、太い枝、電線付近など危険を伴う作業は専門家へ依頼してください。

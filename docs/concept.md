# AI Pruning Assistant コンセプト

## アプリの目的

庭木の剪定に慣れていない人が、木の写真と現在の悩みをもとに「どの枝から確認すべきか」「どの程度の剪定が安全か」を整理できる個人用アシスタントを作る。

剪定を自動で断定するのではなく、判断材料、撮影不足の箇所、安全上の注意を分かりやすく提示することを重視する。

## 想定ユーザー

- 自宅の庭木を自分で手入れしたい人
- 剪定の基礎知識が少なく、どこから確認すべきか迷っている人
- 樹木ごとの状態や作業履歴を継続的に管理したい人

## 最初に作る機能

- 木の写真を複数アップロードしてプレビューする
- 樹木名を入力する
- 希望する剪定の強さを選ぶ
- 気になる点を自由入力する
- 入力後にダミーの診断結果を表示する
- スマートフォンでも操作しやすい画面にする

## 将来作る機能

- ChatGPT APIまたはGemini APIを利用した画像・文章診断
- 剪定後のイメージ画像生成
- 作業日、作業内容、写真などの履歴保存
- 剪定前と剪定後の写真比較
- 複数の樹木を個別に管理する機能
- 季節、地域、樹種を考慮した剪定アドバイス
- 元写真に赤線や番号を重ねて切る候補を示す機能

## AI診断で出したい内容

- 現在の時期から見た剪定の可否
- おすすめの剪定方針と剪定の強さ
- 優先して切る枝
- 切らない方がよい枝
- 病害虫や枯れ込みの可能性
- 作業時の安全上の注意点
- 診断精度を上げるために次に撮影するとよい写真
- AIだけでは判断できず、専門家への相談が必要な条件

診断結果には根拠と不確実性を含め、写真だけでは断定できない事項を明示する。

## 画像生成機能の注意点

剪定後のイメージ画像は、実際の枝構造や成長を保証するものではない。生成画像と元写真の違いを明示し、完成予想ではなく方針を共有するための参考図として扱う。

また、次の点に配慮する。

- 切断位置が実物と一致するとは限らないことを表示する
- 元写真を保持し、生成画像と明確に区別する
- 過度な剪定や危険な作業を誘導する表現を避ける
- 赤線や番号を使う場合は、候補と確定指示を区別する
- 個人宅や周辺環境が写る写真の保存・送信方法を明示する
